# Aerosol icon project
 
### An open source set of icons for aerosol instrumentation

[![DOI](https://img.shields.io/badge/DOI-10.5281%2Fzenodo.22691988-blue.svg)](https://doi.org/10.5281/zenodo.22691988)

A public icon pack for a range of common aerosol-related devices, provided as SVGs (a subset) or in PPTX (full icon set). Sample icons are shown below.

## Missing icons

Desired icons that may be missing from this icon set can be indicated by raising an issue against this repository. 

## Design principles

Contributions should attempt to adhere to the following principles: 

1. Instrument manufacturer logos are not explicitly used to avoid direct advertising and to avoid the unwarranted use of logos. 

2. Icons have a somewhat standardized size and line width. This is currently loosely enforced in the PPTX, where all icons have a line width of 1.25 px and a similar overall size in most cases. 

3. A limited color palette on a per instrument basis, as well as a somewhat limited color palette across different icons. For example, a limited number of shades of blue are used across the icon set. 

4. Moderate amounts of detail. Enough to make the icon unique and recognizable, without adding too much visual clutter. This occasionally means removing some of the details of the instrument but allows for increased consistency, less dense icons, and the ability to scale the icons to smaller sizes.
